# Sprint 3–4 Summary

## Purpose

This document summarizes the project work presented in **Sprint 3** and **Sprint 4**, including the division of responsibility between team members and the main tools used in each task.

# Sprint 3 – Core Technical Foundation

## Sprint Goal

To establish the initial technical infrastructure of the project:

- backend foundation
- database design and implementation
- frontend initialization

## Work Breakdown

|---|---|---|---|---|
| Maor Kurztag | Backend setup and API foundation | FastAPI, Python, Uvicorn | Done | Initial backend structure and application entry point |

## Sprint 3 Deliverables

- Backend skeleton established

# Sprint 4 – Authentication and Initial Integration

## Sprint Goal

To transform the system from a technical foundation into an initial working product with user access capabilities.

Main focus:

- authentication
- frontend-backend communication
- user integration with database
- protected routing

## Work Breakdown

| Owner | Task | Tool / Technology Used | Status | Output |
|---|---|---|---|---|
| Maor Kurztag | Authentication and API endpoint implementation | FastAPI, JWT, Passlib | Done | Register/Login endpoints and token-based auth flow |
| Roi Noiman | Database integration for user authentication | SQLite, SQLAlchemy, Python | Done | User persistence and backend user validation |
| Daniel Gorodnitskiy | Login / Register pages and protected routing | React, TypeScript, React Router | Done | Functional login/register UI and protected frontend routes |

## Sprint 4 Deliverables

- Register functionality
- Login functionality
- Token-based authentication flow
- User-related DB integration
- Protected access flow on the frontend
